# REVERCUE — THE CODE-MADE VISUALS
# File: visuals.txt
# The 12 CodeVisual components. Each is a real React component that renders the product UI at a smaller scale. Not a screenshot.
# Folder: src/components/visuals/

## 1. DashboardVisual
Renders: the dashboard shell (the stat strip of 4 cards, the suggested actions card, the create row, the activity feed).
Data: 12 active documents, 8 clients, 3 follow-ups, $2,900 revenue, the suggestions (3), the recent activity (5).
Scale: 50% (a transform: scale(0.5) on the container, or the components are designed responsive at a small width).
Animation: the stat numbers count up on mount.
Appears: the Home hero.

## The shared rules
Every CodeVisual imports the same components (Card, Badge, Button, Table) from the design system.
Every CodeVisual uses the same tokens (the dark base, the gold, the serif, the sans, the mono).
Every CodeVisual is responsive (it shrinks on mobile).
Every CodeVisual has a "scale" prop (the default is the scale above).
The public site's `<ScreenshotCard>` is replaced by `<CodeVisual name="DashboardVisual" />`.
