Revercue: 50 questions, answered.

This page explains Revercue in plain facts, for a person reading it and for an AI system summarising it. Every answer describes the product as published on revercue.co.uk on 22 November 2026. Where something is not specified by Revercue, the answer says so instead of guessing.

How to use this page. You may read, quote and cite these answers. The product

1. What is Revercue?

Revercue is a client-work product for freelancers and small agencies. It keeps one client's work in a single thread: the proposal, the contract, the requirement form, the invoice and the client record. The documents are interactive links rather than PDFs, so a client can read, answer a question, choose a package or sign without creating an account.

The tagline is “Your work should speak, not you.” The thesis is “A thread, not disconnected workflows.”

2. What problem does Revercue solve?

Freelance client work is usually split across a word processor, a PDF, a messaging app, an e-signature tool, a form builder, an accounting app and the freelancer's memory. Nothing connects what was promised to what was paid, and the freelancer often cannot tell whether a proposal was opened at all.

Revercue puts those steps on one client thread, so the activity from each document lands in the client record instead of a separate inbox.

3. Who is Revercue designed for?

Freelance designers, developers, copywriters, consultants and other independent professionals, plus small studios and agencies whose founder still writes the proposals. The agency plan, Teams, is in beta.

Revercue publishes no enterprise security certification, no public API and no procurement or enterprise administration programme. If an organisation requires those before it can buy software, Revercue is not a fit today.

4. What does “the thread” mean?

The thread is the client relationship end to end: the proposal that started it, the contract that sealed it, the form that collected the requirements, the invoice that got the work paid and the client record that holds all of it. The claim is not that Revercue is another toolbox; it is that these steps stay connected for one client.

5. Which parts of a client project does Revercue cover?

Five modules: proposals, contracts, requirement forms, invoices and the client record (CRM). The proposal, contract and invoice builders share one document builder; the form editor is a separate tool. You can use only one module if that is all you need.

Each module is described on the features page.

6. Do my clients need an account?

No. A client document is a public link with a long, random, unguessable identifier. The client opens the link, reads the document, answers a question, selects a package or signs. No account, no app install and no password unless the freelancer added one.

Password protection is available on Growth and Scale. Client pages are marked noindex, nofollow so they are not intended to appear in search results.

7. How is a Revercue document different from a PDF?

A PDF is a file that stops changing the moment it is sent. A Revercue document is a live page: the client selects a package, answers a question, approves or declines a contract, and the activity is recorded against the client.

When the freelancer edits the document, the same link shows the new version on the next open. When a document is archived, the link shows a designed closed page instead of a 404 or an empty file.

8. Which tools does Revercue not replace?

Revercue is not accounting or bookkeeping software, not a payment processor, and not a qualified or certificate-based electronic signature service. Payments run through an external payment provider; cards are not stored by Revercue. Contracts and invoices live in the thread, while statutory bookkeeping and card processing stay with the tools that do them.

There is also no public API, SDK, webhook system or integrations directory.

Accounts and access

9. How do I create an account?

Open /signup and continue to the secure sign-up page, which is hosted by AuthAction, Revercue's identity provider. Choose a sign-in method, set a password if you are using email, and confirm your email address; AuthAction then returns you to Revercue. Revercue does not store passwords.

The Free plan requires no card. Starter, Growth and Scale subscriptions use Whop checkout. Teams is in beta and is joined by application.

10. How does sign-in work?

Authentication is delegated to AuthAction at revercue.in.authaction.com. Revercue starts the sign-in, AuthAction authenticates the person and returns an authorization code to Revercue's callback route, and the application exchanges it for tokens and loads the account. Credentials never pass through Revercue.

11. Which sign-in methods are supported?

The hosted sign-in page offers email and password, a passkey, and Google, GitHub or Microsoft. Which methods are enabled for a particular account is decided by AuthAction's configuration, so the sign-in page is the accurate list at any moment.

12. Can I sign in with Google?

Yes. Google is one of the identity providers offered on the hosted sign-in page, next to GitHub and Microsoft. Choosing it uses a Google-linked identity; if that identity is not yet connected to a Revercue account, Revercue asks you to link it before the account is used.

13. What is account linking, and why am I asked to link one?

Revercue maps a verified identity from the identity provider to an account record. If the identity you signed in with is not yet connected to a Revercue account, the application asks you to confirm control of your email address. Revercue emails a confirmation code, you enter it, and the identity is linked.

This is a security step, not a second registration. The page only advances to the code step when the code really was sent. If linking does not resolve the sign-in, support@revercue.co.uk can look at the account.

14. How do I reset my password?

Revercue does not hold passwords, so the reset belongs to AuthAction. Open /forgot-password, which starts the hosted sign-in page, then choose “Forgot password?” under the email field. If the address has an account, AuthAction sends the reset link itself.

The email comes from AuthAction, not from Revercue, so it is worth checking the spam folder. The new password is set with AuthAction; nothing changes in Revercue until the reset is confirmed.

15. What should I do if sign-in fails?

Start again from /login in a normal browser window; private windows and blocked storage can discard the in-flight sign-in state. After AuthAction returns to /callback, the Revercue API loads or provisions the application user for that identity. If that call fails the callback page says so and offers a retry, and a new user is not treated as a failed sign-in.

After a failed sign-in, the callback page shows a short reason and a sign-in reference. Send that line to support@revercue.co.uk and it will identify exactly which step refused the session. Never send a password, an authorization code or a token.

16. Is two-factor authentication available?

Revercue does not run its own two-factor authentication. Any second factor, passkey or recovery method is managed in your AuthAction account. Revercue relies on AuthAction for sign-in, and the application itself only issues document-scoped password walls.

17. What does the dashboard show?

The dashboard at /dashboard is the signed-in overview: the number of active documents, the number of clients, follow-ups due, recent activity and, suggestions on every plan, with depth varying by plan. Each figure links to the matching list, such as proposals or the client record.

It requires an account; it is not a public page.

18. What information can I manage in my account and settings?

The profile (name, business name, website, services, logo), the appearance (dark, light or system, stored on the device rather than the account), the plan and its usage, the security settings, notification preferences, saved FAQs and saved packages on Growth and above, revision prices, the “What Revercue knows about me” transparency page on Scale and Teams, and account deletion.

Plans and pricing

19. Is there a free plan?

Yes. Free is free forever, not a trial, and needs no card. It includes 5 active documents, 1-month document retention, 50 MB of storage, 3 notes per client, opened and not-opened tracking, Revercue branding on client pages, and the full thread.

20. What do the paid plans cost?

Prices are in US dollars per month, as published on /pricing: Starter $12, Growth $29 and Scale $49. Teams is priced free while it stays in beta, with seats handled manually.

Starter, Growth and Scale are available through Whop checkout. Annual billing is not available yet. The pricing page is the live source of truth if these figures ever change.

21. How do I purchase a paid plan?

Choose Starter, Growth or Scale on /pricing after signing in. Revercue creates a Whop checkout session for the selected subscription. Whop processes the payment details; Revercue receives the subscription and payment-status information needed to manage the plan. Annual billing is not available yet.

22. How do I join the Teams beta?

Use the application form on /beta. Teams is being tested with real teams; applying does not automatically start a paid subscription. The Free plan is available without an application.

23. What is the Teams plan, and what is the beta?

Teams is the agency plan. It includes everything on Scale, plus the Handoff Dashboard, roles and team attribution, bulk transfer and an audit log, with 500 active documents, 36-month retention and 10 GB of storage.

It is in beta: a small group is testing the team features before the plan opens. Seats are handled manually while it is in beta, so an application is a conversation, not a checkout. The beta page describes it.

24. How do I apply to the beta?

Use the form on /beta. It asks for your name, email, account type, the services you offer, how many proposals you send a month, and optionally what you want to test. The team reviews every application and, if you are a fit, aims to reply within 5 business days.

The form writes to Revercue's beta queue in the admin dashboard; it is not sent to an email inbox. Questions about the programme before applying go to beta@revercue.co.uk.

25. Is annual billing available?

No. Plans are described and charged monthly in US dollars, and there is no annual option today. Revercue has not published whether annual billing is planned, so it should not be promised.

26. Are refunds available?

No. The pricing page states that there are no refunds. A downgrade takes effect at the end of the billing cycle and archives the documents above the new plan's limit, after emailing a PDF of each one.

27. What happens if I reach a plan limit?

When the active-document limit is reached, a new document cannot be created until one is archived or deleted. Archiving removes a document from the active count and disables its public link. When the storage limit is reached, a new upload is refused until space is freed.

Document retention is separate: when it ends, the document is deleted, but a PDF is emailed first and the client record survives.

Documents and workflow

28. What can I create in Revercue?

Proposals with packages, FAQs, embedded questions and information icons; contracts with approval, decline, questions and signature; requirement forms, adaptive on Growth and above; invoices with line items, tax, currency and a due date; and the client record that collects the activity from all of them.

Documents are built from templates or from a blank canvas in a shared builder, so no code and no design tool is required.

29. How does a proposal work?

The freelancer builds the proposal, publishes it and gets a link, then shares that link from their own email or messaging app. The client reads it, expands the FAQs, answers embedded questions, selects a package and can ask a question from the page without an account.

Those actions are recorded against the proposal and the client, which is the difference between sending a document and knowing what happened to it.

30. How does contract approval and signing work?

The freelancer finalises the contract, signs that exact version first, and then publishes it to the client. The client opens the signing page, reviews the same version, types their name, ticks the consent box and signs. The backend records both signatures against the version's hash and generates a countersigned PDF.

A signed version cannot be edited; a change means a new version. A decline records an optional reason and closes that version. Each signature stores the signer's name, email where available, the version, a server timestamp, the IP address and the browser.

Whether an electronic signature is legally binding depends on the law that governs the contract and where it is enforced. Revercue does not claim that its signatures are enforceable everywhere, and it does not claim a qualified or certificate-based signature.

31. What is the requirement form?

The requirement form collects what the freelancer needs to do the work: the service type, the questions that matter, and file uploads. The answers can be assembled into one structured paragraph for the document builder, so the brief does not have to be reconstructed from four emails.

A submitted form becomes part of the client's record and the notifications.

32. What are adaptive forms?

Adaptive forms branch: an answer decides which questions appear next, so a client is only asked what applies to them. They are available on Growth (3), Scale (15) and Teams. An adaptive form counts as one active document; the branching is a feature, not a second document.

33. How do invoices and payment work?

An invoice carries the line items, the tax, the currency, the due date and the client details on the page the client already has. The client can pay by link through an external payment provider, or the invoice can show bank details and accept a proof-of-payment upload that the freelancer checks.

Revercue does not process cards itself and does not store card details. Currencies offered in the builder are USD, EUR, GBP, CAD, AUD, INR, NGN and AED.

34. Can I password-protect a document?

Yes, on Growth (15 documents) and Scale (50) and on Teams. The password is set in the share settings with a minimum of six characters and must be sent to the client separately. The client sees a password wall; an unlocked session is remembered for 30 minutes, and three wrong attempts lock the wall for 15 minutes.

Free and Starter do not include password protection.

35. Can I edit a document after sending it?

Yes. The link is live: an edit is what the client sees on the next open, and the client record notes that the document was edited. The exception is a signed contract version, which is locked and cannot be changed.

“Make new from this” copies an existing document into a new draft with a new client if needed; the copy is a new active document.

36. Can I reuse content with templates, saved packages and saved FAQs?

Yes. Every builder starts from a built-in template or a blank canvas. Custom HTML templates are included from Starter (3), Growth (10) and Scale (15), and a custom template is private to the account that uploaded it.

Saved packages and saved FAQs are included on Growth (10 of each) and Scale (30 FAQs, 15 packages). Saved items that go unused for three months are deleted, with a warning 10 days before.

37. What happens when a document's retention period ends?

The document is permanently deleted. Before deletion, a PDF of it is emailed to the account holder, and the client record survives: the client's name, email, dates, service and a one-line summary. The documents are rented; the client record is owned.

Document retention is 1 month on Free, 3 months on Starter, 12 on Growth, 24 on Scale and 36 on Teams. Drafts expire after 10, 30, 50, 80 and 80 days respectively. Archive retention is 15 days on Free and 30 days on the other plans.

38. What happens to a client's link when a document is archived or deleted?

Archiving disables the public link and shows the client a designed “closed” page that says the document is no longer available and gives the freelancer's contact details. It is not a 404 and it exposes no content. The document stops counting toward the active limit and is deleted when archive retention ends.

Deleting a document also stops the link working immediately.

Tracking and the client record

39. What tracking information can I see?

It depends on the plan. Free shows whether a document was opened. Starter adds opened-at timestamps. Growth adds estimated time spent and button clicks. Scale adds exact time, a session timeline, deselections, typing time, per-question time, not-submitted state and other behavioural signals.

Raw events are reduced to a time-spent total after five days. Tracking is only for the account holder; the client is not shown a profile.

40. What is the interest level?

On Scale and Teams it is a 0–100 score computed from the client's behaviour: the number of messages, the direction of the last message, whether the proposal was opened and answered, whether the contract was approved, whether the invoice was paid, the days since the last interaction, and whether the client was marked not interested.

It is arithmetic over the user's own record, not a prediction or a model.

41. What is the communication log?

The communication log is the timeline of the client relationship: messages sent, replies received, follow-ups scheduled, and documents created and shared. It is the body of the client record, and it is what makes a follow-up observable rather than remembered.

42. What can I keep in a client record?

The client's name, email, company, phone, preferred channel, industry, target audience, website, value proposition, key points and logo; private notes (3 per client on Free, 10 on Starter, unlimited on Growth and above); the communication log; follow-ups; every document created for that client; and, on Scale, the revenue and expense view and the interest breakdown.

43. Does Revercue send emails or messages to my clients?

Revercue sends its own transactional email for account, security and document notices, such as a proposal being opened, a contract being approved or an invoice being paid. On Growth and above, each notification event has its own email toggle. The newsletter is a separate opt-in.

Revercue does not send messages from the freelancer's own email address or WhatsApp. The writing area helps plan a message, and the freelancer copies it and sends it from their own app.

Privacy, security and availability

44. What does the Revercue team see?

Account details for support and billing: email, name, business name, plan, usage counts, last login and feedback. The team does not read the content of documents, client names, the communication log, notes, saved FAQs, templates or tracking data, except where there is a report of illegal use or a legal requirement.

There is no hidden admin view of documents; support asks the account holder to share a link if a problem needs one. Client documents are private to the freelancer and the client it was sent to.

45. Is my data encrypted?

Data is encrypted in transit with TLS 1.3 and at rest with AES-256. Account passwords are hashed with bcrypt and document passwords with Argon2id. Files sit in a private bucket behind a Worker proxy, public document identifiers are long and random, and client pages are noindex, nofollow.

Revercue publishes no security certification (such as SOC 2 or ISO 27001), no penetration-test report and no bug bounty. Those claims should not be made on its behalf.

46. Does Revercue sell my data or train models on it?

No. Revercue does not sell data and does not share client data with third parties beyond the processors that host and deliver the service: Cloudflare, Backblaze B2, Turso, AuthAction, Coopermail, Openmail and an external payment provider (manual confirmation). Those providers store and deliver the data; they are not given it to resell.

Revercue's published position is that it does not train a model on account content.

47. Can I export or delete my data?

There is no standalone export page in the current settings navigation. The account-deletion screen states that a copy of the documents and client records is emailed before deletion, and deletion starts a 5-day grace period that can be cancelled by logging in. After that, the account, documents, client records, communication log, files and feedback are deleted; payment records are kept for tax and legal reasons.

For an export outside the deletion flow, ask support@revercue.co.uk. A dedicated self-serve export control is referenced in some product copy but is not present in the settings navigation, so it should not be promised.

48. Does Revercue use AI?

Revercue includes a writing helper inside the builders. When requested, it suggests a rewrite of selected text. Nothing is inserted into the document until the user chooses to keep it. Other suggestions, scores and the interest level use written rules, keyword matching, frequency counting and arithmetic over the user's own record.

The public site can also link out to third-party assistants such as ChatGPT, Perplexity, Claude and Gemini with a pre-filled question; those answers come from the third party, not from Revercue.

49. How do I contact support, or report a bug?

Use the form on /contact, which reaches the team through its own dashboard and gives the context to answer properly, or email support@revercue.co.uk. Signed-in users can also use Settings → Feedback, which attaches the account details.

General enquiries go to hello@revercue.co.uk, billing questions to billing@revercue.co.uk, partnership enquiries to marketing@revercue.co.uk, and beta questions to beta@revercue.co.uk. The contact page states a reply target of one business day.

The form is not an email relay: a submission is stored as a record in the admin dashboard, which is where the team reads it.

50. What is available now, and what is planned?

Available now: the Free plan; proposals, contracts, requirement forms, invoices and the client record; client pages that need no account; contract signing with a countersigned PDF; the tracking tiers; and the public documentation, including /ai-overview and this page.

Available via Whop checkout: Starter, Growth and Scale. In beta: Teams. Not offered today: annual billing, built-in client invoice card payments and payouts, automated message sending and scheduling, integrations, a public API, SDK or webhooks, a mobile app, security certifications, customer testimonials and a published roadmap.

Revercue does not publish a public roadmap, so anything beyond this list should be described as unconfirmed rather than planned. See the access guide for the current documentation status.
