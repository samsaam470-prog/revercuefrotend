### 3. System (the default mode)
The mode follows the OS preference (the `prefers-color-scheme`). If the OS is dark, the app is dark. If the OS is light, the app is light.
The system mode is the **default** for a new user. The user can change it in Settings -> Appearance.

## THE TOGGLE (Settings -> Appearance)
A segmented control: [Dark] [Light] [System]. The current mode is highlighted (the gold).
The "System" label: "Follow your device's setting."
The change is saved to `localStorage` (`revercue_mode`: `dark` | `light` | `system`).
On app load, the `ThemeProvider` reads the `localStorage` and applies the mode. If `system`, it reads the `prefers-color-scheme` media query.

## THE CSS
The `tokens.css` has the `:root` (dark) and the `[data-theme="light"]` (light). The `ThemeProvider` sets the `data-theme` attribute on the `<html>`.
The components use the CSS variables (no hardcoded colours). The gold rule holds in both modes: the gold is the accent, the primary button.
The public site, the dashboard, the builders, the client pages, the admin: all use the same tokens. The mode is global.

## THE RULES
- The dark mode is the default. The light mode is optional. The system mode is the default for a new user.
- The gold is the accent in both modes. The gold rule holds.
- The six states (default, hover, focus, active, disabled, loading, error) are in both modes.
- No "AI", no "MVP", no "Payoneer", Teams in beta (the copy).
- The FormSubmit copy is exact.
- The auto-save, the notification badge (piggybacked), the gold rule: unchanged in both modes.
