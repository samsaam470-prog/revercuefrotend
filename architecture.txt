# REVERCUE — FRONTEND ARCHITECTURE
# File: architecture.txt
# The stack, the folder structure, the routing, the API client, the state, the build order.

## THE STACK
React 18 + TypeScript + Vite. React Router v6. TanStack Query (server state). React Context (auth, toast, plan). React Hook Form + Zod. Lucide React. The fonts: Instrument Serif (display/headline), Inter (body/label), JetBrains Mono (mono). The build: Vite -> dist/ -> Cloudflare Pages. The API: VITE_API_BASE_URL=https://revercue-api.samsaam470.workers.dev.

## THE API CLIENT
src/api/client.ts: the fetch wrapper (the base URL, the auth header, the JSON body, the error shape, the 401 -> /session-expired). Each module (auth.ts, proposals.ts, etc.) is the typed function that calls the client. No invented endpoints. Every function maps to api.txt.

## THE STATE
Server state: TanStack Query (the query keys: ['proposals'], ['proposals', id], ['crm', 'clients'], ['dashboard', 'summary']). The mutations invalidate the keys.
Auth: AuthContext (the user, the token, the login, the logout, the isAuthenticated).
Plan: PlanContext (the plan, the hasFeature).
Toast: ToastContext (the toast.success/error/info).
Notification badge: piggybacked on the page responses (the dashboard summary, the list responses). No separate poll.
Auto-save: the useAutoSave (the 60-second interval + the session-end beacon + the explicit save).

## THE BUILD
dev: npm run dev (Vite, localhost:5173). build: npm run build (tsc + vite build -> dist/). preview: npm run preview. typecheck: tsc --noEmit. Deploy: Cloudflare Pages (the build command, the output dir dist/, the VITE_API_BASE_URL).

## THE RULES
No Tailwind. No UI kit. Plain CSS with the tokens. No CSS-in-JS. No invented endpoints. No fake data in production. No stock photos. No AI claims. No "MVP". No "Payoneer". Teams is in beta. The gold rule. The six states. The Fieldset. The empty state. The FormSubmit copy is exact. The auto-save is the 60-second interval + the beacon + the explicit save. The notification badge is piggybacked. The client-facing pages carry the freelancer's brand.
