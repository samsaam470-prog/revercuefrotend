# REVERCUE — WHAT IT IS (updated)
# File: revercue.txt
# Read this first. The rules are in rules.txt.

## The tagline
"Your work should speak, not you."

## The thesis
"A thread, not disconnected workflows."

## The product
Revercue is a SaaS tool for freelancers and agencies. It keeps the client work in one thread: proposal, contract, requirement form, invoice, client record.

## The core feature (every plan)
The interactive document link. Create a document, publish it as an unguessable public link, the client opens it without an account, reads it, interacts, and the freelancer sees the activity.

## The flagship
The thread. The continuous flow from proposal to payment, all linked to the same client, all visible in one record.

## The 5 modules + the sub-module
- Proposals: the interactive links with packages, FAQs, embedded questions, info icons, the password protection.
- Contracts: the Approve / Decline / I Have Questions, the after-approval chain, the signature block.
- Requirement Forms: the adaptive forms with branching, the Prompt Creator, the icons in the options.
- Invoices: the pay-by-link or account details + proof upload, the confirm payment.
- CRM: the client record, the communication log, the writing area, the notes, the follow-ups, the interest level (Scale), the revenue tab (Scale), the 15-day summary.
- The Document Builder (the sub-module): the canvas, the block library, the properties panel, the template selection, the template model, the auto-save, the preview, the share.

## The four-layer pipeline
1. The search (the Worker): Wikipedia, FreeSerp, DuckDuckGo, OpenStreetMap, Openverse, Wikimedia, Iconify.
2. The organization (the helper): the structured JSON from the samples' idea.
3. The pattern fix (the Worker): the user's patterns, the client's history, the missing sections.
4. The visual intelligence (the helper): the images, the icons, the charts, the diagrams, the SVGs.

## The pattern engine
The instructions, the patterns, the pairings. The suggestions are basic on Growth, advanced on Scale. The learning is arithmetic on the user's own data.

## The no-AI rule
The product does not use AI. It uses patterns. The helper is the local model (the rewrite, the suggestion, the review). The footer has four buttons (ChatGPT, Perplexity, Claude, Gemini) with a pre-filled prompt. The product does not claim AI.

## The no-MVP rule
The plans are "available now", "invite-only", "in beta". No "MVP", no "v2", no "v3".

## The no-Payoneer rule
The paid plans are invite-only. Join the waitlist. The team reaches out when a spot opens. The Free plan is available now.

## The retention model
The documents are rented; the CRM record is owned. The PDF is emailed before the deletion. The CRM record survives.
