# REVERCUE — API CONTRACT
# File: api.txt
# Every endpoint the frontend calls. The request body, the response shape, the error codes.
# Base URL: https://revercue-api.samsaam470.workers.dev
# Auth: Authorization: Bearer <user_jwt> for user routes; Bearer <admin_jwt> for admin routes; none for public routes.
# Content-Type: application/json for all requests and responses, except file uploads (multipart/form-data) and CSV/PDF downloads.
# Error shape: { "error": "error_code", "message": "Human-readable message.", "details": {} }
# Error codes: invalid_payload, unauthorized, forbidden, not_found, conflict, rate_limited, plan_limit_reached, config_error, internal_server_error.
# Status codes: 200 ok, 201 created, 400 validation, 401 auth, 403 forbidden/plan, 404 not found, 409 conflict, 429 rate limit, 500 server.
# Pagination: ?page=1&limit=50 -> { data: [], pagination: { page, limit, total, total_pages } }
# Timestamps: ISO 8601 strings.

## AUTH (/api/auth)
POST /api/auth/signup — { email, password, tos_accepted: true, newsletter_opt_in } -> 201 { success, token (pre-auth), user }
POST /api/auth/login — { email, password } -> 200 { success, token, user } OR { success, requires_2fa: true, pre_2fa_token } OR { success, requires_verification: true, token (pre-auth) }
POST /api/auth/google — { id_token } -> 200 { success, token, user }
POST /api/auth/verify-email — Bearer pre-auth, { code } -> 200 { success, email_verified: true, token }
POST /api/auth/resend-verification — Bearer pre-auth -> 200 { success, cooldown_seconds }
POST /api/auth/2fa/verify — { code, pre_2fa_token } -> 200 { success, token, user }
POST /api/auth/2fa/resend — { pre_2fa_token } -> 200 { success, cooldown_seconds }
POST /api/auth/password-reset/request — { email } -> 200 { success: true } (always)
POST /api/auth/password-reset/verify — { email, code, new_password } -> 200 { success: true }
GET /api/auth/me — Bearer user -> 200 { user }
POST /api/auth/logout — Bearer user -> 200 { success: true }

## THE RATE LIMITS
Signup: 5/hour/IP. Login: 5/15min/IP. OTP resend: 1/90sec/user, 5/hour/user. 2FA: 3 attempts/code. Password reset: 3/hour/email. Change password: 3/hour/user. Public document: 100/hour/IP. File upload: 20/hour/user. Admin login: 5/15min/IP. General: 300/min/user.
